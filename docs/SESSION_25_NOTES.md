## Архитектурные решения (зафиксировано с владельцем)
1. **Один помощник на всех.** Модель мозга/голоса/видео — одна (глобально). Персонализация (имя, манера, голос, история) хранится по **user_id / комнате**, помощник НЕ дублируется на каждого пользователя. «Кто кому ответил» — по комнате/user_id.
2. **Карточка core-агента «Помощник Джим» = единый пульт** настроек помощника (мозг + голос + видео). Core-агенты (вне Города) обрабатывают систему.
3. **Местоположение модели** разделено на два слоя: инфраструктура (облако / наш сервер / своё железо — endpoint+ключ в `config.py`: `SELF_TTS_URL`, `SELF_VIDEO_URL`, `YANDEX_SPEECHKIT_*`) и выбор (провайдер+модель). Переезд на своё железо = смена URL endpoint'а.
4. **Голоса в настройках пользователя — заглушки-примеры.** Реальный список голосов придёт из выбранной TTS-модели.
