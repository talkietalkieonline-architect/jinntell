## 🧭 Решения по эпикам (в память, не в код)
- **Поток-хаб**: Поток = дом + голос-первый режим рендера для ЛЮБОГО чата (медиа снизу из дымки, не облака). Помощник = персональный core-джинн-проводник. Забота, не навигатор.
- **Комнаты + фоновый помощник**: чат/комната → единый разговор с N; помощник слышит все чаты своего юзера, диспетчерит джиннов; правила комнаты + помощник + core. Правило «мне отключиться?» при чате п-п.
- **Опрос джиннов**: 2 круга (вектор→пинг вместо LLM-вопроса), избранное + 5-7 из Города, двойник отвечает сам; журнал = лог переговоров.
- **Каналы с памятью**: источник (Фонтанка RSS + KudaGo API) → датированный RAG → поиск по свежести + Guardian; новостник = дайджест голосом + «подробнее» (память, затем веб).
- **Тарифы пользователя**: Free / Плюс (личное RAG) / Профи (свой я-джинн). Биллинг payer-agnostic УЖЕ готов (personal→user платит). Надо: поле `plan` + гейты, помесячная подписка, приём платежей. НЕ делать юзеров контрагентами.
- **Джинн-охранник** (защита ввода) — слой 2 поверх штатной защиты (SQLAlchemy параметризован, React экранирует), на базе журнала.
