## 1. Главный экран / Лента
- ✅ Лента оживает: событие при входящем DM (когда не в чате) + карточка «Канал: N непрочитанных»
- ✅ Обновление ленты (poll 20с + feed_ping)
- 🔴 Больше событий в Ленту: ответ джинна, приглашение в комнату, системные/платёжные
- 🟡 Кружки ленты чатов: долгое нажатие → быстрое меню (закрыть/приглушить)
- 🟢 Реордер/закрепление; Витрина/статусы (истории джиннов)

## 2. Нижняя панель (голос-первый)
- 🔴 Переделать: минимум кнопок, всё неголосовое — в одно меню (пользователь рисует макет)
- 🟡 Индикатор «слушаю», стабильность распознавания (Android)
- 🟢 Аудио-голосовые сообщения (запись звука)

## 3. Чат
- ✅ Лайтбокс, удаление, поиск по чату, меню «три точки», запись о звонке
- ✅ Кросс-чат пересылка (текст/медиа в другой чат/комнату/джина)
- 🟡 Реакции, reply-цитата
- 🟡 «Пожаловаться» (заглушка)

## 4. Помощник
- ✅ Интеллект: понимание намерений + переспрос при непонятном
- ✅ Зовёт джинна из Города (поиск по имени/смыслу → чат)
- ✅ Команды: открой/закрой/отправь/переслать/очистить/избранное
- 🔴 Веб-поиск («найди в сети») — ждёт ключ (реком. Tavily), сейчас заглушка
- 🟡 Больше команд: позвонить X, «отправь фото X» (реальная отправка)

## 4b. Динамическая память + внутренние агенты (см. docs/MEMORY-AND-AGENTS.md)
- 🔴 Память-экстрактор помощника (факты о юзере, дедуп, инжект, чистка)

## 5. Помощник видит медиа (НОВОЕ)
- 🔴 Мультимодальная модель — чтобы помощник реально «видел» фото/видео
- 🔴 Медиатека пользователя (его загруженные фото/видео, доступ помощнику)
- 🟡 Доступ к соцсетям (Telegram/VK) через их API — брать фото/видео с разрешения

## 6. Видео-ответ (talking-avatar)

- 🔴 Привязка модели видео-генерации к агенту; видео-позиция в реестре (себест. за рендер)
- 🟢 Live-аватар в звонке, онлайн замена лица (Syntx-стиль)

## 7. Вход / профиль
