# JinnTell — Бэклог доработок

Порядок: от главного экрана вглубь. 🔴 важное · 🟡 средне · 🟢 потом.
Каналы — отдельный крупный блок, отложены.

## 1. Главный экран
- 🟡 Кружки ленты: долгое нажатие → быстрое меню (закрыть/приглушить)
- 🟢 Реордер/закрепление чатов
- 🟢 Витрина/статусы (истории джиннов/бизнесов) — надстройка
- 🔴 Лента-экран: наполнение (какие события) + карточки
- 🟡 Клик по событию → открыть чат; пометить/убрать

## 2. Нижние контролы
- 🔴 Внешний вид: размещение и функции кнопок (пересмотр)
- 🟡 Индикатор «слушаю», стабильность распознавания (Android)
- 🟢 Аудио-голосовые сообщения (запись звука)

## 3. Чат
- 🟡 Реакции, reply-цитата, пересылка
- 🔴 «Отправь картинку/медиа в другой чат/комнату/джину» (кросс-чат отправка)
- 🟡 «Пожаловаться» (сейчас заглушка)
- 🟢 Доставлено/прочитано в DM

## 4. Помощник
- 🔴 Помощник зовёт/приглашает джинна из Города (поиск джинна по имени/смыслу → открыть/в комнату)
- 🔴 Понимание команд: чёткий разбор + поведение при непонятной/новой команде
      (например «найди мне в сети» → веб-поиск; «отправь картинку в чат X»)
- 🟡 Больше команд: позвонить X, очистить историю, найти джинна про…, в избранное
- 🟡 Веб-поиск (инструмент) для помощника и джиннов
- 🟢 Нативный wake-word (Porcupine), фон/сон

## 5. Оживление джиннов / видео
- 🔴 Talking-avatar: джинн и помощник отвечают в кружке ВИДЕО+ГОЛОС
- 🔴 Привязать к агенту модель видео-генерации (провайдер типа Syntx: замена лица, онлайн)
- 🟡 Свой голос джинна (TTS) в кружке; синхрон губ
- 🟢 Онлайн замена лица в звонках

## 6. Город и джинны
- 🔴 Платные джинны: UX «замок»/цена, экран перед платным общением (флаг is_paid есть)
- 🟡 Динамический фильтр профессий (из данных)
- 🟡 Личный я-джинн: редактор внешности/манер/голоса
- 🟡 Discovery-2+: теги, «похожие», по интересам
- 🟢 Импорт агентов из GitHub

## 7. Соцслой и звонки
- 🔴 TURN-сервер (coturn) — видео за строгим NAT
- 🔴 Push-входящие (звонки/сообщения) на закрытом приложении — нативка
- 🟢 Групповые звонки, демонстрация экрана

## 8. Монетизация / биллинг
СДЕЛАНО: учёт токенов, плательщик (контрагент/пользователь/бесплатно), реестр моделей
(себест./продажа за 1млн, срок, провайдер), маржа, сводка.
- 🔴 Баланс/кошелёк контрагента и пользователя + списание
- 🔴 Подписка пользователя (голос помощника, внешность, лимиты) + оплата
- 🟡 Лимиты/«расширенные ответы» (кроме бизнес-джиннов)
- 🟡 Пополнение (ЮKassa)
- 🟢 TTS/видео как отдельные платные позиции в реестре

## 9. Кабинет контрагента (ЛК бизнеса)
- 🔴 Свои джинны, расход/счета, баланс, пополнение
- 🟡 Диалоги/лиды, анализ переговоров, доп-сервисы

## 10. Настройки / профиль
- 🟡 Реальный пол (приватно) vs образ (публично) — логика безопасности
- 🟢 Приватность/блокировки

## 11. Инфраструктура и безопасность
СДЕЛАНО: шифрование сообщений at-rest, звонки E2E.
- 🔴 TURN (см. 7)
- 🟡 Нативное приложение (push, wake-word, звонки в фоне)
- 🟢 Опциональные E2E для человек↔человек DM
- 🟢 Свап/лимиты на сервере под соседа baraban.online

## 12. Джинн-каналы (ОТЛОЖЕНО, крупный блок)
- Модель канал/пост/подписка, fan-out-on-read
- Автопостинг джинна (планировщик + генерация LLM) — «ведут сами»
- UI канала, «Подписаться», посты в Ленте
- Витрина как срез свежих постов
- Токены автопостинга списываются с владельца (контрагента)
