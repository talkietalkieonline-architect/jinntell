# JinnTell — Динамическая память и внутренние агенты

## Идея (согласовано)
Всё заточено на обслуживание пользователя → помощник (и опц. джинны) должны
ПОМНИТЬ факты о пользователе и «взрослеть» на накопленной информации.

## Динамическая память (экстрактор)
Паттерн: mem0 / MemGPT-style «reflection».
- **Триггер:** пользователь закрыл чат ИЛИ замолчал (idle). Реализация — фоновый
  планировщик каждые ~5 мин: берём пользователей с новыми репликами, у кого
  последнее сообщение старше ~2 мин (= замолчал).
- **Экстрактор:** дешёвый LLM прогоняет новые реплики пользователя → JSON-факты
  (имя, город, работа, интересы, планы…). Пустой трёп («привет/как дела») → [].
- **Хранение:** факты в Qdrant (коллекция `_user_memory`, payload {user_id, fact}).
  Эмбеддинги — Yandex. Прогресс — таблица `memory_state {user_id, last_msg_id}`.
- **Анти-клогинг (важно, вопрос владельца):**
  - храним ФАКТЫ, не сообщения → трёп не оседает;
  - дедуп при upsert (похожий факт по эмбеддингу > порог → не добавляем);
  - порог уверенности; (на будущее — декей/TTL, суммаризация старой истории).
- **Возврат:** в диалоге семантический поиск фактов по текущему сообщению →
  топ-K инжектится в промпт помощника (как персона). Так помощник «помнит».
- **Чистка:** пользователь может очистить свою память (кнопка в настройках →
  удаляет его точки из коллекции). Плюс дедуп не даёт расти.
- **Инфраструктура:** отдельный микросервис НЕ нужен — фоновая задача в бэкенде
  (как планировщик новостей). Выделить в микросервис — опция при росте нагрузки.

## Внутренние (core) агенты — РАЗДЕЛЯЕМ роли
Две разные задачи, разные SLA — НЕ смешивать в одном агенте.

### 1. Страж / Контролёр (в петле, синхронно) = оживить «Агент Контента» (id 3)
- Уже существует как core-агент, но в рантайме ничего не делает.
- Задачи: анти-галлюцинации (ловить выдумки джиннов), guardrails на входе
  (не давать вытягивать запрещённое/джейлбрейк), контроль качества.
- Латентно-критичен (на пути ответа) → быстрый, отдельный промпт.

### 2. Память / Архивариус (вне петли, асинхронно) = НОВЫЙ core «Агент Памяти»
- Задачи: на закрытии/молчании извлекать факты, upsert в вектор, отдавать recall.
- Фон, без спешки, отдельный промпт/триггер.

Оба — agent_type=core, пользователю не видны, делят инфраструктуру, но это два
раздельных сервиса.
