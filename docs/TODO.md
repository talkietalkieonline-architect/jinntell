_Актуально на 2026-07-27. Переписан под реальность после сессии 22–27 июля (закрыто ~40 пунктов, старый список устарел)._

## ✅ Закрыто в сессии 22–27 июля (в проде)
- **Журнал действий** — модель `activity_log` + сервис + вкладка в админке (фундамент Шерифа/аналитики).
- **Починка docker-compose** — база/ключи брались из хардкода, рестарт клал прод; привязано к `.env`.
- **Баги:** зеркало видео-кружка, выход из Потока (возврат откуда зашёл), стоп-кнопка озвучки, сжатие медиа (аватары 512 / картинки чата 1280 / видео-кружки 480+0.8Мбит).
- **Центр управления:** заголовки секций, «О себе»→«Статус», возраст помощника (assistant_age), профиль на 2 части (Официальные / Образ), смена/задание пароля.
- **Характеристики общения** помощника (тон/длина/юмор/эмодзи) + расширены интересы (32 темы).
- **Шрифт** на все окна (root font-size) + ступень «Очень крупный».
- **Фон:** свой фон (загрузка), группировка Стандартные/Анимированные, бегунок скорости + палитра анимации.
- **Рамка/декор аватара** (кольца + цветы/сердечки/звёзды) — видят другие.
- **Все агенты на DeepSeek** (Gemini/Grok из РФ нужен прокси; модель выбирается в АДМИНКЕ, не в коде).
- **Каналы с памятью (СТАРТ):** «Новости СПб» кладут новости в RAG → агент отвечает по реальным новостям, а не выдумывает. Забэкфилл 300 постов.

## 🎯 Критический путь к живому Городу + контрагентам (ближняя цель владельца)
1. 🔴 **Классификация джиннов** — ЖДЁТ документ владельца (корпоративные/коммерческие/жители/…). Предпосылка ко всему B2B.
2. 🔴 **RAG-наполнение специалистов** — знания только у Кости (ПДД), помощника, Новостей. Остальные ПУСТЫ → галлюцинируют. № 1 контент-разрыв. Нужен **Docling** (разбор PDF прайсов/законов) + лёгкий скрейпер (RAM 3.8ГБ!).
3. 🔴 **Платные джинны UX** — «замок»/цена перед платным общением (флаг `is_paid` есть, UX нет).
4. 🔴 **Приём платежей** (ЮKassa) — упирается в мерчант-счёт (у владельца пока нет).

## 🔴 Эпики (слой Jinniverse — обсуждено, в памяти)
- **ДНК-слой** — Big Five + состояние (энергия/стресс) как данные на агенте, модулируют промпт. Дёшево, фундамент под эмерджентность. См. `vision_jinniverse`.
- **Поток-хаб** — Поток = дом + голос-первый режим рендера для любого чата (медиа снизу из дымки). См. `vision_flow_home_hub`.
- **Комнаты + фоновый помощник** — чат/комната = разговор с N; помощник слышит все чаты, диспетчерит; правило «мне отключиться?». См. `design_rooms_and_ambient_assistant`.
- **Опрос джиннов помощником** — 2 круга (вектор→пинг), избранное+5-7 из Города. См. `design_assistant_polling`.
- **Тарифы пользователя** — Free / Плюс (личное RAG) / Профи (свой я-джинн). Биллинг payer-agnostic готов; надо `plan` + подписка + оплата. См. `design_monetization`.
- **Языки / i18n** — один язык на юзера; прототип EN+KA (грузинский текстом, голоса KA нет). См. `vision_languages_i18n`.
- **Джинн-охранник** — защита ввода, слой 2 поверх штатной (журнал = глаза).
- **Джинн-маркетолог** (внутренний, админ-only) — отчёты о прогрессе + рекомендации постов; старт с истории разработки; автоматизация постинга через MCP/сервисы позже.
- **Маркет/Магазин** · **Образование** · **Двойник (personal)** — уровни автономии.
- **Видео-кружки** (talking-avatar) — GPU (аренда РФ) + SadTalker. Север владельца → видео-генерация.
- **Синтетические фокус-группы (B2B)** — Aaru-путь; ров = калибровка по реальным данным (гео/кассы).
- **Цифровая Память** (памятники ушедшим) — дальняя, тяжёлая по этике.

## 🔭 Стратегия (не задача — в памяти)
**Jinniverse** = три бизнеса в одной вселенной: B2B фокус-группы (клин/кормит) · живой город (витрина + ground-truth) · Цифровая Память (дальняя). Общий субстрат: ДНК + память + Core-министерства. Heartbeat дешёвый (математика, НЕ LLM у каждого — иначе разорение). Референс: aaru.com. Полное — в памяти `vision_jinniverse`.
