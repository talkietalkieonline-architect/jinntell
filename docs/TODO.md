## 🟢 Мелкие / быстрые
- [ ] **Классификация джиннов** — ждёт утверждения владельца (готовое предложение: админка/Город/Избранное).
- [ ] **LeftPanel «Режимы»** — остаток старого переключателя режимов, убрать.
- [ ] **Флаер геотриггера** — сейчас ссылка на картинку; нужна **загружаемая картинка / QR прямо в чат** (не ссылка). Приоритет владельца 3.
- [ ] **Звонки за NAT** — TURN/coturn подняты; проверить живым звонком между устройствами (возможно, открыть порты у хостера: UDP/TCP 3478, 5349, UDP 49160–49200).

## 🟡 Средние
- [ ] **Поток v2** — wake-word вместо кнопки, красивее субтитры, привязка к реальному заказу/броне. (v1: экран + кнопка + голос + TTS — сделан.)
- [ ] **RAG-наполнение** — знания есть только у Кости (ПДД) и помощника (справка о платформе); остальные специалисты пустые.
- [ ] **Каналы** — постит только «Новости СПб»; другим джиннам сделать автопостинг канала через LLM.
- [ ] **Онбординг+** — сейчас спрашивает имя; расширить (голос помощника, интересы, аватар).
- [ ] **Sparse-BM25 гибрид** — для редких формулировок RAG (лёгкий лексический гибрид уже есть).
- [ ] **Guardian input-guardrails** — сейчас только анти-галлюцинации на выходе; добавить защиту от джейлбрейков на входе.
- [ ] **Admin / Железа агенты** — заготовки-промпты, не оживлены (мониторинг платформы/железа).

## 🔴 Крупные эпики
- [ ] **Маркет / Магазин** — вкладка «Товары и услуги» в Городе, подборка помощником (опрос джиннов-продавцов → комната с предложениями), вкладка «Магазин» у контрагента, обязательный джинн-продавец.
- [ ] **Образование** — лекции (запись/пауза/вопросы), human-in-the-loop (джинн переспрашивает живого эксперта), регистрация у образовательных компаний; тип «образовательные» в классификации.
- [ ] **Двойник (personal)** — джинны пользователей ещё не создаются; уровни свободы/автономии (от «советует» до «ведёт бизнес сам»).
- [ ] **Приём платежей** — ЮKassa (упирается в РС/мерчант), подписка пользователя, пополнение баланса/кошелёк.
- [ ] **Видео-кружки (аватар-генерация)** — нужен GPU.
