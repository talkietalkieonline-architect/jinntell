## ✅ Сделано и в проде (главное)

### Помощник переведён с классификатора на tool-calling
- `services/llm.py::deepseek_tools()` — function calling через DeepSeek (OpenAI-совместимо).
- `services/assistant_agent.py` — агент-луп: модель сама выбирает инструменты и компонует многошаговые действия. Backend-инструменты исполняются на сервере; клиентские (open_chat/close_chat/call/send_message) возвращаются директивами фронту.
- Эндпоинт `POST /api/chat/assistant-act` → {reply, directives, steps}. Пишет обмен в историю (jim-{uid}) — чинит «помощник пропал».
- Фронт (page.tsx): `assistantAct` + `runDirectives` заменили classifyIntent+classifyAndAct. `pushUser`/`pushAssistant`. Fallback в обычный чат при ошибке.
- **Личность/память/знания в лупе**: _build_context подмешивает персону (имя/пол/возраст/характер), память о юзере (memory.recall), знания о платформе (RAG core-агента jim). Параметры под качество Gemini: temperature 0.6 + frequency_penalty 0.3 (из PDF-чеклиста владельца).

### Настройки помощника
- Характер (Interstellar): ползунки Юмор/Теплота/Прямота/Формальность (assistant_traits).
- Инициатива разговора: assistant_initiative (proactive/reactive/command).

### Система интересов / реклама / барьер (эпик vision_interest_curation — построен целиком)
- **Профиль интересов**: помощник растит через разговор (remember_interest/forget_interest/list_interests). Хранение с датой подтверждения.
- **Уточнение интересов**: залежавшиеся (>21 дня) — помощник переспрашивает «всё ещё актуально?» (confirm_interest/forget_interest). Интересы не вечны.
- **Движок таргетинга** `services/targeting.py`: посты джиннов в Qdrant (channel_posts), match_for_user (семантич. матч интересы↔посты), fan-out-on-read.
- **Барьер**: согласие (approaches!=off) + интересы + блок-лист (личный семантический + глобальный проектный).
- **Блок-лист**: личный (block_topic/unblock_topic/list_blocked, в памяти помощника) + ГЛОБАЛЬНЫЙ проектный (services/moderation.py, GLOBAL_BLOCKLIST, админка → Система). Enforced в таргетинге + промптах джиннов + помощника.
- **Посты джиннов**: `targeting.publish_post` + форма в админке (карточка джинна → Управление). Доставка избранникам (📢) + по интересам (✨).
- **Доставка в Ленту**: feed.py list_feed — fan-out-on-read с ленивой материализацией (топ-3, троттл 5 мин, дедуп). Помощник приносит по запросу (check_feed).
- **Тап события Ленты** → чат джинна (link_room).
