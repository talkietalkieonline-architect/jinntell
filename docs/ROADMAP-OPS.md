# JinnTell — Операционка и бизнес-задачи (вне кода)

Техника опережает операционку — это нормально. Ниже — что понадобится
к запуску с реальными деньгами и контрагентами. Не всё сразу.

## Юридическое
- [ ] ИП/ООО (юрлицо для приёма платежей и договоров)
- [ ] Пользовательское соглашение + Политика конфиденциальности (152-ФЗ)
- [ ] Публичная оферта / договор с контрагентом (бизнесом)
- [ ] Согласие на обработку ПДн, правила Города (что можно/нельзя джиннам)

## Финансы / приём денег
- [ ] Расчётный счёт в банке (для счетов контрагентам)
- [ ] Эквайринг / платёжный провайдер (ЮKassa / CloudPayments) — пополнение баланса
- [ ] Онлайн-касса (54-ФЗ) — чеки при оплате
- [ ] Тарифы и прайс: цена за 1 млн токенов, подписки, пакеты (ЦИФРЫ — техника готова)
- [ ] Правила списания/возвратов

## Учёт / автоматизация
- [ ] 1С или аналог (Мой Склад / Контур.Бухгалтерия) — учёт, счета, акты, НДС
- [ ] Связка биллинга с бухгалтерией (выгрузка расхода контрагентов из админки)

## Контент / модерация
- [ ] Правила модерации джиннов и сообщений
- [ ] Источники для каналов (новости и т.п.), проверка прав на контент
- [ ] Наполнение Города качественными джиннами (в т.ч. с RAG-знаниями)

## Поддержка / метрики
- [ ] Канал поддержки (можно джинн-поддержка + человек)
- [ ] Метрики: DAU, расход токенов, выручка/маржа (часть уже в админке)

## Данные / надёжность
- [ ] Бэкапы БД + хранить SECRET_KEY (иначе не расшифровать сообщения!)
- [ ] Политика хранения/удаления данных

# Продуктово-техническое (осталось, кратко — детали в BACKLOG.md)
- Биллинг: блокировка при нуле, подписка пользователя, ЮKassa
- Платные джинны: экран «это платно, X ₽» перед разговором
- ЛК контрагента (свои джинны, счета, баланс, пополнение)
- Онбординг новичка (первый сценарий: «Скажи: Джим, найди…»)
- Нижняя панель (минимум кнопок — по твоему макету)
- Видео-аватар (GPU + SadTalker), помощник видит медиа (мультимодаль)
- TURN (видеозвонки за NAT), нативка (push/wake-word)
- Каналы: автопостинг через LLM, подписки, лента постов
- RAG-знания джиннов (ПДД/штрафы и т.п.) — заново залить и проверить
- Telegram-вход + аватар из Телеги
